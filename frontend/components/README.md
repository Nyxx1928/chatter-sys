# Components Directory

This directory contains all React components for the chat application.

## Structure

- **chat/** - Chat-related components (MessageList, MessageInput, UserList, RoomSelector)
- **auth/** - Authentication components (LoginForm, RegisterForm)
- **ui/** - Reusable UI components (Button, Input, Card)

## Guidelines

- All components should be TypeScript with proper type definitions
- Use 'use client' directive for client-side interactive components
- Follow mobile-first responsive design principles
- Ensure accessibility with semantic HTML and ARIA labels
