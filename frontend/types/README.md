# Types Directory

This directory contains TypeScript type definitions for the application.

## Files

- **models.ts** - Domain model types (User, ChatRoom, Message, RoomMembership)
- **api.ts** - API request and response types
- **stomp.ts** - STOMP message payload types

## Guidelines

- Use interfaces for object shapes
- Use enums for fixed sets of values
- Export all types for use throughout the application
- Keep types aligned with backend DTOs
